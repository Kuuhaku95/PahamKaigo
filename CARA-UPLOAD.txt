CARA MEMASANG & MEMPERBARUI PAHAMKAIGO

PASANG PERTAMA KALI (Cloudflare Pages, gratis)
1. Daftar di https://dash.cloudflare.com
2. Workers & Pages > Create > Pages > Upload assets
3. Nama proyek: pahamkaigo  → seret SELURUH isi folder ini
4. Link: https://pahamkaigo.pages.dev → buka di HP → "Install aplikasi" / "Tambahkan ke layar utama"

MEMPERBARUI
1. Buka proyek pahamkaigo > Create new deployment
2. Seret SELURUH isi folder versi baru (termasuk sw.js dan version.json)
3. Pengguna otomatis melihat banner "Ada pembaruan materi" saat membuka aplikasi.
   Tidak perlu install ulang.

PENTING: jangan ganti nama proyek / link.

CATATAN: upload juga file gambar hero.webp dan semua ic-*.webp (ada di folder utama, bukan subfolder).
